# iOSobscura

A native iOS client for [iosapps.litten.ca](https://iosapps.litten.ca/) ("Legacy iOS App
Finder"), a community instance of the open-source
[iOSobscuraServer](https://github.com/CatsLover2006/iOSobscuraServer) - a directory of
archived iOS apps and their old `.ipa` versions.

The app lives in [`iOSobscura/`](iOSobscura/) and is built with
[xtool](https://github.com/xtool-org/xtool), SwiftUI, and no third-party dependencies.
See [`iOSobscura/README.md`](iOSobscura/README.md) for setup, build commands,
architecture, the feature checklist against the website, and known limitations.
